# Changelog

Notable changes to Swiftly are recorded here. Swiftly is experimental, and
features may change between releases.

## [1.0.0] - Initial public release

- Publish the experimental Electron browser with search, tabs, bookmarks,
  history, Reader Mode, focus minutes, and configurable privacy settings.
- Include an independent local crawler and search prototype that works without
  Electron or external search providers.
- Document installation, privacy behavior, development, and the local search
  workflow.
- Add contribution guidance, issue forms, a pull request template, and the
  project Code of Conduct.
